# Короткое задание следующему этапу

Создай алгоритмическую программу `program(weights)` в `design_weights.py`, которая
записывает FP32 NumPy-тензоры GraphNet Torus9 8×120 с нуля. Архитектуру не меняй.
Сначала прочитай [EXPERIMENT_PROTOCOL.md](EXPERIMENT_PROTOCOL.md) и
[PREPARATION_REPORT.md](PREPARATION_REPORT.md). Схема: `experiment_cli.py schema`.

Сначала выполни только `zero-pass --writer design_weights.py --output <новая-версия>`.
Никаких forward, позиций, партий, обучения, fitting или optimizer на этом этапе.
Все параметры, включая LayerNorm scales, начинаются с нуля. Пустой шаблон и demo
не являются результатом эксперимента.

После успешного zero-pass оператор может разрешить сессию с бюджетом 10/25/50.
Тогда запрашивай позиции/игры явными отдельными командами, анализируй JSON-отчёты,
исправляй программу и сохраняй каждую версию в новой директории. Бюджет 0 запрещает
все диагностические команды. Не запускай длинные турниры без отдельного задания.
Arena использует закреплённый M269 из `reference-lock.json`, одинаковый MCTS и коми.

Никаких платных API, запуска другой Astra, production изменений или удаления весов.
Отчитай отдельно о структурной корректности и измеренной игровой силе.
